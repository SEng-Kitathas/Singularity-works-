## Current ownership model
The primary PCMMAD Lab work surface is **Forge itself and Singularity Works as a whole system**. The App is the **frontend / user-experience arm** of that system.

This supersedes current-looking prior wording that assigned the App broad ownership of “product/runtime/security” or made App security pressure the default whole-project frontier. Those statements remain historical evidence of the earlier working split but are not current ownership doctrine.

Current split:
- **Singularity Works** = the complete product/system whole.
- **Forge** = the core semantic/evidence/transformation engine and primary technical system work surface inside that whole.
- **PCMMAD Lab** = responsible for Forge plus whole-system Singularity Works coherence, architecture, qualification, integration boundaries and system-level technical direction.
- **App** = frontend UX/client embodiment: presentation, interaction, operator-facing workflow and feedback/pressure against Forge/system interfaces.
- App artifacts may provide runtime/security/integration evidence where useful, but **App evidence does not own the whole-system roadmap or canonical truth**.

The next planning pass SHALL therefore audit the Forge/Main/Core + whole-system open seams before selecting new consequence-bearing work. Candidate whole-system seams include canonical semantic/currentness/snapshot completion, LBE/semantic-map capability, system composition/transformation contracts, recovery/integration boundaries and other Singularity Works system functions. Selection requires current evidence; this note does not pre-select one.
